## 🚀 Getting Started

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Reet-Kamlay/DSA.git
   cd DSA
   ```

2. **Compile and run a program:**
   - For C++ files:
     ```bash
     g++ filename.cpp -o output
     ./output
     ```
   - For C files:
     ```bash
     gcc filename.c -o output
     ./output
     ```

   *Replace `filename.cpp` or `filename.c` with the actual file name you wish to compile.*
